Acerca del Sistema

JUSTICIA ARGENTINA es un sistema de resolución asistida por inteligencia artificial diseñado como copiloto para jueces argentinos.

Principios de diseño

  • Quaestio facti: la fija el juez. El sistema no modifica los hechos probados.
  • Quaestio iuris: el sistema aplica el derecho a los hechos dados.
  • Copiloto: propone un proyecto de sentencia que el juez revisa, modifica y firma.
  • Transparencia: toda norma y precedente citado es verificable.
  • Congruencia: la sentencia se pronuncia sobre todo lo pedido por las partes.

Niveles de complejidad

  • Nivel 1 (Rutinario): Subsunción clásica. Norma clara, jurisprudencia pacífica.
  • Nivel 2 (Difícil): Problemas interpretativos — indeterminación lingüística (vaguedad, ambigüedad), problemas sistemáticos (lagunas, antinomias, redundancia), conflictos temporales, interpretación teleológica incierta, analogía.
  • Nivel 3 (Constitucional): Tensión entre principios constitucionales, casos de derrotabilidad. Requiere test de proporcionalidad.
